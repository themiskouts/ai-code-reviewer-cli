# AsterAI - Automated Code Analyzer

AsterAI is an AI-powered code review web application built for educational purposes.
It analyzes code snippets or uploaded source files and returns instant feedback
covering performance, edge cases, potential bugs, and severity ratings.

## Features
- AI code review powered by Google Gemini (with Groq fallback)
- Automatic language detection and syntax highlighting
- Category classification with cloud-synced analytics
- Submission history with search and delete
- Severity rating system (Clean / Needs Work / Critical Issues)

## Tech Stack
Python · Streamlit · Google Gemini API · Groq API · Supabase
